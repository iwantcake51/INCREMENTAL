# Brass Orrery

A live solar system you can play with, all in one HTML file with no build step.

- **Real orbits.** All eight planets follow elliptical orbits from NASA JPL orbital elements, so their positions on any date are close to real.
- **Real facts.** Each planet has a facts card (size, mass, gravity, day and year length, moons, air, temperature) from NASA's fact sheets.
- **Moons, the asteroid belt and Earth's satellites,** which grow from Sputnik in 1957 to today's swarms.
- **Life on each planet.** An animated scene for each world, and what scientists actually know about life there.
- **Tech timeline.** Real space history up to today, then a projected (made-up) future to 2600: settlements, cargo traffic and a Dyson swarm.
- **Space war.** Five fictional powers fight over the settlements, with weapons that get stronger over time.
- **Detonate planets.** Blow up any planet and watch its debris spread along the old orbit. You can rebuild them.

## Run it

Open `index.html` in a browser. That's it.

## Controls

| Action | How |
| --- | --- |
| Rotate or tilt the view | Drag on the sky |
| Select a planet | Click it, or pick it from the list |
| Detonate a planet | Double-click it, or press **Detonate** |
| Change speed | 1d/s, 1mo/s, 1y/s or 10y/s |
| Jump in time | Date box, **Today**, or **Jump to next milestone** |
| Start the war | **Space war** card, then fast-forward past 2060 |
